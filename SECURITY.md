# Security

Ploeg is experimental. The latest 0.x release is the development baseline; no long-term supported release line exists.

Do not disclose credentials, exploit details or private deployment data in a public issue. Use GitHub private vulnerability reporting if the repository's Security tab offers it. If unavailable, open a minimal issue asking a maintainer to establish a private reporting channel; include no vulnerability details.

A maintainer will arrange private triage, remediation and coordinated disclosure. No response-time guarantee is established yet. Enabling and testing private vulnerability reporting is tracked in the project backlog.
