# Ploeg — name and mark

"Ploeg" and the Ploeg mark identify this project. They are trademarks of the
Ploeg project, held by its maintainers.

The software is [Apache-2.0](../../LICENSE). So are the files in this
directory — but §6 of that licence grants no rights in trade names or marks, and
that carve-out is deliberate. This page is what fills it.

Settled in [ADR-0022](../adrs/0022-the-name-and-mark-are-trademarks-not-cc-licensed-artwork.md).

## You may, without asking

- Reproduce the **unmodified** mark, wordmark or lockup to refer to Ploeg — in
  articles, talks, slides, README badges, ecosystem and integration listings,
  comparison tables, screenshots.
- State truthfully that your software **works with**, **supports**, **integrates
  with** or **is built on** Ploeg.
- Link to the project using the name and mark.
- Scale the assets, and use any of the supplied colour, monochrome, white or
  tile variants.
- Redistribute an **unmodified** Ploeg as Ploeg — a distribution package, a
  container image, a chart mirror — as long as it is unmodified.

No permission request, no notification, no fee.

## You may not, without written permission

- Ship a **modified or forked** distribution under the name Ploeg or under the
  mark. Fork the code freely — Apache-2.0 says you may — but give it your own
  name.
- Use the name or mark in a way that implies **endorsement, affiliation,
  sponsorship or certification** by the Ploeg project.
- Use the name or mark, or anything confusingly similar, as **your own** product
  name, company name, domain name, app-store listing or social handle.
- **Alter** the mark: change its proportions, streek weight, corner radius or
  the two-colour split; recolour it outside the supplied palette; rotate it;
  add effects; or combine it with another mark into a new one.
- Present the mark as the most prominent element on materials that are not the
  project's own, in a way that suggests the material comes from us.

## Using it correctly

`docs/brand/README.md` carries the construction, the palette with measured
contrast, the lockups, clear space and minimum sizes. The short version:

- Clear space: one streek weight on every side.
- Minimum size: 16 px for the mark (use `favicon.svg` below 32 px), 96 px wide
  for the horizontal lockup.
- Never re-set the wordmark in a live font. Use `wordmark.svg`; it is outlined.

## Questions, and permission

Anything this page does not clearly allow, ask. Open an issue on the project
forge, or write to the maintainers. We would rather say yes to a specific
request than have this page guessed at.

If you spot a misuse, telling us is welcome and is not an accusation.
